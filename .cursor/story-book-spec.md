# 目的
既存のブログプロジェクトにStorybookを導入し、アプリケーション本体とは別のカタログサイトとしてVercelで公開するためのセットアップを行いたい。

# 要件
- 同一リポジトリ内にStorybookを同居させるスタンダードな構成とする
- パスエイリアス（例: `@/*`）やグローバルCSSなど、既存プロジェクトの設定をStorybook側でも読み込めるようにする
- 既存のUIコンポーネントを1つ選び、サンプルのStoryを作成する
- vercel環境にアップ予定で、story-bookのサイトは、運営者以外見れないようしたい

# 実行ステップ
以下のステップに従って、実装と提案を行ってください。

## 1. Storybookの初期化
- プロジェクトのルートディレクトリで `npx storybook@latest init` を実行する想定で、必要なパッケージを追加し、`.storybook` ディレクトリを生成してください。
- （※パッケージマネージャーはプロジェクトで現在使用しているものに合わせてください）

## 2. 既存環境との連携設定
- ブログ本体のグローバルCSS（Tailwind CSSなどを使用している場合はその設定も含む）がStorybook上でも当たるように、`.storybook/preview.ts` 等を適宜修正してください。
- プロジェクトでパスエイリアスを設定している場合、Storybookでも解決できるように設定を追加・修正してください。

## 3. サンプルStoryの作成
- プロジェクト内の既存のUIコンポーネント（ボタンやタグ、記事カードなどシンプルなもの）を1つピックアップし、それに対するStory（`.stories.tsx` または `.stories.ts`）を作成してください。
- Controls（GUIでの値変更）が機能するように、argsを適切に設定してください。

## 4. Vercelデプロイ用の手順まとめ（私への指示）
- Vercel上で「Storybook専用のサイト」としてデプロイするために、私がVercelのダッシュボードで行うべき設定手順をマークダウンでまとめて教えてください。
- 特に以下の項目を明記してください。
  - Build Command（例: `npm run build-storybook`）
  - Output Directory（例: `storybook-static`）
